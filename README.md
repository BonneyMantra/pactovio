# Pactovio

The pre-sales engine for technical B2B suppliers. Three doors in (public tenders, inbound RFP/RFQ, design requests) feed one engine that reads, extracts, decides, matches, answers and prices, then checks and approves. Out come the buyer's own forms filled, a compliance matrix, a proposal and a priced quote, plus events to your team's tools and a 24x7 agent chat.

Built for the Nebius x NVIDIA hackathon (Best Apps & Agents). Full README to follow.

- API: `apps/api` (Cloudflare Worker, Hono). See `docs/API.md`.
- Shared contracts: `packages/contracts`, typed client: `packages/client`.
